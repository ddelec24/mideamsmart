# Журнал изменений плагина Midea MSmart

>**IMPORTANT**
>
>Если информация об обновлении отсутствует, значит, оно касается только документации, перевода или текста.

# 16/10/2026

- Первая бета-версия (0.9.0) для проверки на реальных устройствах: ждём ваших отзывов на форуме
- Создание плагина: базовая структура, страница настройки и страница оборудования
- Установка зависимостей: автономный Python 3.13 (через uv) и отдельное виртуальное окружение плагина
- Демон на Python (asyncio): запуск, корректная остановка, связь с Jeedom и передача списка оборудования
- Синхронизация устройств: учётная запись MSmartHome, поиск в локальной сети, создание и обновление оборудования
- Получение token и key с проверкой на устройстве и кнопка для повторного запроса
- Защита от блокировки учётной записи Midea (коды 7610 и 65027)
- Автоматический широковещательный адрес по умолчанию (все сетевые интерфейсы)
- Локальное управление кондиционерами (AC) и коммерческими кондиционерами (CC) через msmart-ng: состояние, периодический опрос, недоступное устройство
- Команды создаются по возможностям каждого устройства, со стабильными кодами для сценариев и кнопкой обновления
- Параметры оборудования: звуковой сигнал, шаг уставки, энергопотребление
- Локальное управление осушителями (A1) через midea-local: режим, вентилятор, уставка влажности, резервуар, качание, ионизатор, насос, защита от детей, фильтр
- Сигналы о заполненном резервуаре и фильтре отображаются зелёным или красным значком
- Окно диагностики для каждого оборудования с копированием сводки без секретов для форума
- Автоматический поиск в локальной сети устройств, сменивших IP-адрес
- Блокировки облака и отклонённый пароль запоминаются даже после перезапуска демона
- Оборудование отмечается как timeout, когда устройство не отвечает, страница «Здоровье» и сведения для форума
